# ADR-003: Fixed illustrative topology

Status: accepted for Phase 0 baseline, 2026-09-06.

## Context
Arbitrary topology editor and OEM CAD reproduction add scope without improving initial performance explanations.

## Decision
CPU/RAM/NVMe/GPU/VRAM/interconnect logical slots with inventory bindings and illustrative laptop positioning.

## Consequences
Document placement abstraction; unsupported components remain visible with unavailable metrics.

Validation is governed by docs/19-ROADMAP.md. Revisit through a superseding ADR,
not an undocumented implementation shortcut.
